# Anbanantham T - Interactive Developer Portfolio 🚀

A high-performance, cross-platform portfolio built with Flutter Web and a Supabase backend. This project serves as a live demonstration of my frontend application development skills and my active transition into Cloud and DevOps architecture.

## 🏗️ Architecture & Tech Stack
* **Frontend:** Flutter Web, Dart
* **Backend:** Supabase (PostgreSQL database, Row Level Security)
* **CI/CD:** GitHub Actions for automated building and testing
* **Cloud Hosting:** Automated deployment to cloud storage 

## ✨ Key Features
* **Cross-Platform UI:** Fully responsive design built entirely with modular Flutter widgets.
* **Dynamic Data:** Project listings and live visitor counters fetched securely from a PostgreSQL database.
* **Live Contact Form:** Integrated directly with Supabase for real-time message handling without third-party mailer APIs.
* **Optimized Performance:** Audited with Google Lighthouse to ensure fast web rendering and high accessibility scores.

## ⚙️ Local Development Setup
1. Clone the repository: `git clone https://github.com/anbanantham-tech/portfolio.git`
2. Install dependencies: `flutter pub get`
3. Configure environment variables for Supabase in a `.env` file.
4. Run the development server: `flutter run -d chrome`
